# FocusFlow - To Do Board

Aplicación web de una sola página (SPA) para la gestión visual de tareas estilo Kanban, desarrollada con HTML, CSS y JavaScript plano.

---

# Vista General

FocusFlow es un tablero de productividad inspirado en herramientas modernas de organización de tareas.  
La interfaz permite visualizar tareas distribuidas en diferentes estados:

- To Do
- In Progress
- Done

El proyecto fue construido sin frameworks ni librerías externas de JavaScript, utilizando únicamente tecnologías base del navegador.

---

# Tecnologías Utilizadas

- HTML5
- CSS3
- JavaScript Vanilla
